# Project Instructions

## Coding Conventions
Before writing or modifying code, read `docs/Conventions.md` in its entirety.

Follow its Luau typing, naming, module structure, control flow, dependency usage, and implementation requirements.

## Development Principles

* Inspect the existing repository structure and relevant APIs before implementing anything.
* Follow established project architecture and reuse existing utilities.
* Prefer simple, focused, maintainable implementations over unnecessary abstraction.
* Keep changes scoped to the requested feature.
* Do not introduce dependencies without a concrete need.
* Ensure all Luau code is strictly typed.
* Do not assume Roblox Studio plugin APIs behave a certain way; verify their usage against existing code or documentation.

## Workflow

1. Inspect the repository and relevant documentation.
2. Determine the appropriate implementation.
3. Implement the requested functionality completely.
4. Run available formatting, linting, and validation tools.
5. Summarize the implementation and any remaining limitations.
